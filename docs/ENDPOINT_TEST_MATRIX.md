## Known gaps in this matrix (stated, not hidden)

- `com.auditlog.exception` is the lowest-covered package (67%) — some error-handler branches (e.g., the generic fallback paths) aren't exercised by a dedicated test, only incidentally by whichever error case happens to trigger them.
- No dedicated boundary/malformed-input test suite beyond what exists per-endpoint (`docs/EVALUATION_CLOSURE_MATRIX.md` item 20, `TEST-03` — not started).
- Database fault/rollback tests (item 11) and PII/log-injection tests (item 18) are not implemented — see `docs/DECISIONS.md` ADR-014 for why, and `ENGINEERING_SUMMARY.md` for the complete list of scoped-out items.
